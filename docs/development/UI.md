# Gemsnote 统一 UI 设计

本文描述当前 Web 的 Vue 界面及交互约定。功能范围为笔记工作区、账号管理和系统管理。
不提供公开博客、博客评论或主题；笔记预览和用户间的权限共享继续保留。
桌面客户端专属行为见[桌面 UI 约定](https://github.com/gemsnote/gemsnote-desktop/blob/main/docs/UI.md)。

## 总体布局

工作区为三个面板，没有额外的独立最左全局导航栏：

| 笔记本栏 | 笔记列表 | 正文栏 |
| --- | --- | --- |
| 应用图标、珠玑笔记、新建与收起 | 排序、当前分类、新建与收起 | 笔记标题、操作工具栏 |
| 搜索笔记本、树形笔记本、共享、标签、回收站 | 搜索笔记、笔记条目 | 基本信息、正文预览或编辑 |
| 用户头像 | | 底部标签 |

品牌标题、顶部面板栏和笔记本栏底部使用深绿色背景。品牌由应用图标及较小的黑体
“珠玑笔记”组成，显示文案跟随当前语言。笔记本栏与笔记列表支持拖动分隔线调整宽度。
宽度和折叠偏好按账号保存，不影响笔记数据。

## 笔记本与导航

- 顶部提供新建笔记本和收起按钮，下面为搜索笔记本输入框。
- “所有笔记”“已加星”和各笔记本右侧显示笔记数。笔记本按名称稳定排序，使用树形缩进。
- 子笔记本默认收起，点击父笔记本可展开或收起；搜索用于定位笔记本。
- 笔记本右侧三点菜单提供新增子笔记本、重命名、移动和删除。
- 共享给我、标签和回收站作为独立入口；共享内容须体现访问权限。
- 长笔记本名称以省略号显示，鼠标悬停显示全名。

收起笔记本栏后将其缩为深绿色窄列，顶部仅保留可点击展开的应用图标；底部保留用户
头像。从账号或管理页面回到工作区时默认展开
笔记本栏。笔记列表收起后不保留替代图标，点击笔记本或分类可重新打开列表。

## 笔记列表

- 标题使用当前笔记本或分类名称，不固定写“笔记”。
- 标题栏左侧三横按钮打开排序菜单：修改时间升序/降序、标题升序/降序。
- 右侧依次为普通新建 ＋（富文本）、Markdown 新建 M＋、收起按钮。
- 第二行仅保留搜索输入框，不再显示独立排序框和搜索按钮。
- 条目显示标题、摘要和包含时间的日期；长标题省略并提供悬停全名。
- 不提供独立分页控件或列表/摘要视图切换控件。

## 正文与基本信息

打开已有笔记默认预览，具有写权限时可切换为编辑。富文本和 Markdown 使用对应编辑器，
修改自动保存；不再提供显式保存按钮，标题栏也不显示“已同步/未同步”文本。

顶部左侧为笔记标题，右侧为按权限和笔记状态提供的操作，例如编辑/预览、星标、
图片与附件、移动/复制、共享、历史、导出、恢复和删除。只读共享笔记不能编辑。

工具栏下面直接显示基本信息行，不再提供 Info 按钮或独立 Info 弹层。
从左到右为笔记本、创建时间、修改时间、格式（RT/MD），笔记 ID 靠最右显示。
基本信息和底部标签行使用浅色背景及较小字号，正文使用剩余空间。

未选笔记时展示应用图标，以及“日积字句，终得珠玑。”“选择笔记或开始全新记录。”
英文界面显示对应译文。

## 标签输入与筛选

笔记底部使用独立圆角标签块与输入区。输入时在上方浮动显示当前账号已有标签，
过滤已选标签；上下键选择候选、回车确认，也可点击候选。未选择候选时，回车新增当前文本。
确认后清空输入区以继续输入下一项，标签块的删除按钮可移除标签；空输入时退格删除最后一项。
支持逗号、中文逗号及换行分隔粘贴，忽略空标签并去重；中文输入法选词期间不提交。
Escape 关闭候选，失焦或离开笔记前确认输入。只读笔记只显示标签块，无编辑和删除入口。
界面内使用标签块，保存接口仍传递逗号分隔的 `tags` 字符串。

保存标签变更后重新读取标签及引用计数，更新左侧列表和输入候选；普通正文保存不触发该刷新。
左侧只展示有关联笔记的标签，默认按关联笔记数降序显示前 10 个，同数按名称稳定排序。
过滤框检索全部标签，忽略大小写、不受前 10 个限制；清空过滤恢复前 10 个。
过滤只影响标签列表，不改变当前笔记筛选。

## 移动、复制与输入框

笔记移动/复制及笔记本移动对话框使用可搜索的树形笔记本选择器，展示真实层级，
而不是平铺下拉框。笔记本移动可选择根目录，不能选自己或自己的子树。
两个对话框的取消按钮均位于右下角，使用“取消”而不是“关闭”。
笔记移动/复制成功后及时刷新相关笔记本计数。

输入框聚焦使用墨绿色内侧强调边框，不在输入框外绘制更大的黑框，也不改变布局尺寸。
保留清晰的键盘焦点、禁用和错误状态，编辑器输入不得被全局快捷键抢占。

## 用户菜单

用户头像按钮固定在笔记本栏底部右侧；收起后位于窄列底部。优先显示用户头像，
缺失时使用字符占位。菜单包含账号、语言和退出；语言子菜单支持中文、英文。

Web 直接通过 API2 向服务端保存数据，不提供立即同步、完全同步或重新同步入口。
管理员额外显示管理入口，普通用户不显示。

账号页面以及 Web 管理页面顶部左侧显示应用品牌，右侧使用返回按钮，不重复显示头像菜单。

应用对话框标题和按钮跟随所选语言，操作失败须提供可见的错误提示。

## 窄屏与可访问性

窄屏通过笔记本抽屉、笔记列表/正文切换保留导航，不能要求固定同时展示三栏。
当前 Web 样式在 1100px、700px 附近切换布局，具体以 `frontend/src/styles.css` 为准，
不再采用旧文档的 1200px/768px 布局定义。折叠后仍须能够访问用户菜单。
图标按钮需提供提示和可访问名称，错误和权限状态不能仅靠颜色表达。

## API 与维护边界

Web 使用服务端 API2。客户端实现细节由各客户端仓库维护，不在本文件重复定义。
API2 1.0.0 为首个定稿版本，后续合同变更遵循[API2 版本策略](API2.md)；旧 `/api`
是独立兼容层，不应因 UI 修改改变其合同。服务端不通过模板注入工作区初始数据。

## 验收要点

- 三栏、折叠与返回工作区行为正确，没有独立最左导航栏。
- 新建、排序、搜索、树形移动和计数刷新与上述布局一致。
- 默认预览、自动保存、基本信息行和底部标签行正常，不恢复旧 Info 或保存按钮。
- Web 不显示同步入口，管理入口受权限控制；语言选择覆盖菜单和应用对话框。
- 只读共享权限有效，失败可见。
